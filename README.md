# 🧩 Regular_NIR_Checker

**Коллекция полезных регулярных выражений**  
для анализа, проверки и редактирования научных работ в **LaTeX** — помогает быстро находить и исправлять:
- неверные дефисы и тире  
- неправильные кавычки  
- слова с заглавной буквы после двоеточия  
- слова с маленькой буквы после точки  
  и другие.

ДИСКЛЕЙМЕР:

Регулярки не сделают все за вас, нужно каждое изменение либо подтверждать либо пропускать! Всегда проверяйте что вы заменяете, этот инструмент нужен для указания на возможные огрехи. Да и я не мог все варианты предусмотреть, где то будет идеально, а где то может найти не то что предполагалось, пишите, если что дополним. ## ⚙️ Проверка дефисов и тире

### 1. Дефисы между буквами и числами 

**⭐ Находит дефисы/тире между любыми буквами или цифрами (рус/англ):**
```regex
(?<=[a-zA-Zа-яёА-ЯЁ0-9])[‐-‒–—―⁻-]{1,3}(?=[a-zA-Zа-яёА-ЯЁ0-9])
````

> Из-за
> 
> Привет―Hi
> 
> Foo-98
> 
> MQTT--брокеру
> 
> хай---да

Заменять на: `"--~`
---

### 2. Тире между словами (с пробелами)

**Базовый вариант — одиночное тире:**

```regex
(?<=\s)[‐-‒–—―⁻-](?=\s)
```

> Поршень - это деталь
> 
> Сегодня ― нет

**⭐ Расширенный вариант — находит одинарные, двойные и тройные тире:**

```regex
(?<=\s)[‐-‒–—―⁻-]{1,3}(?=\s)
```

> Поршень -- это деталь
> 
> Поршень --- это деталь
> 
> Поршень ――― это деталь

Заменять на: `"---`
---

### 3. Проверка одиночных дефисов (не входящих в последовательности `"---` `"--~`)

**Описание логики:**

* `(?<!["‐-‒–—―⁻-])` — слева не кавычка и не дефис/тире
* `[‐-‒–—―⁻-]` — сам дефис/тире
* `(?![-~])` — справа не дефис и не `~`

**⭐ Регулярка:**

```regex
(?<!["‐-‒–—―⁻-])[‐-‒–—―⁻-](?![-~])
```

> Используется **после первых двух**, чтобы проверить оставшиеся одиночные дефисы.


## 🪞 Кавычки для замены на «ёлочки»

**⭐Левая кавычка:**

```regex
(?<=[\s("«0-9A-Za-zА-Яа-яЁё])["«](?=[A-Za-zА-Яа-яЁё0-9])
```

**Правая кавычка:**

```regex
(?<=[A-Za-zА-Яа-яЁё0-9])["»](?=(?:[\s\.,;\)»"]|$))
```

## 🔤 Слова с большой буквы после двоеточия

### ⭐ 🇷🇺 Только русские буквы

```regex
(?<=:)\s*[А-ЯЁ][а-яё]*
```
### 🇬🇧 Только английские буквы

```regex
(?<=:)\s*[A-Z][a-zA-Z]*
```

### 🌐 Общий вариант (русские + английские)

```regex
(?<=:)\s*[A-ZА-ЯЁ][a-zA-Zа-яё]*
```
---

### ⭐ С игнором LaTeX-команд между двоеточием и Словом 
(например, списков, где перед списком предложение оканчивается двоеточием, дальше идут команды по типу \begin, \item и первый элемент списка с Большой буквы):

```regex
(?<=:)(?:\s|\\[^\s]*\{[^\}]*\}|\\[^\s]+)*([А-ЯЁ][а-яё]*)
```
Пример:
> Валенок:
> 
> \begin{itemize}
> 
> \item Хлеб
> 
> \item Первый
> 
> \end{itemize}
(тут Хлеб в тексте идет после двоеточия)

---

**Примеры работы:**

*Русский вариант найдет:*

* `сегодня: Вкусность` → `Вкусность`
* `продукт:Москва` → `Москва`

*Английский вариант найдет:*

* `Hello:Куркума` → не найдет (тк второе слово - кириллица)
* `Test: Hello` → `Hello`
* `item:Apple` → `Apple`

*Общий вариант найдет случаи где есть ру и анг буквы:*
* `Hello:Куркума` → найдет

Заменять на: большую на маленькую букву в слове после двоеточия

## 🧠 Слова с маленькой буквы после точки

### 🌍 Общий вариант (рус + англ)

```regex
(?<!\b(?:см|т|д|г|рис|макс|Макс|мин|Мин|сек|Сек)\.)\s*(?<=\.)\s*(?!(?:png|jpg|pdf|jpeg|gif|bmp)\b)[a-zа-яё][a-zA-Zа-яё]*
```

---

### ⭐ 🇷🇺 Только русские слова

```regex
(?<!\b(?:см|т|д|г|рис)\.)\s*(?<=\.)\s*(?!\b(?:png|jpg|pdf|jpeg|gif|bmp)\b)[а-яё]+
```

* `[а-яё]+` — строго русские буквы, минимум одна
* Игнор сокращений (`см.`, `рис.` и т.п.)

---

### 🇬🇧 Только английские слова

```regex
(?<!\b(?:sm|t|d|g|fig)\.)\s*(?<=\.)\s*(?!\b(?:png|jpg|pdf|jpeg|gif|bmp)\b)[a-z]+
```

* `[a-z]+` — маленькие латинские буквы
